## 决策与输入输出

- 已核验本机 Node v22.23.2 `/Users/junjieli/.local/bin/node`，`node:sqlite DatabaseSync` 可用，仍有 ExperimentalWarning。用 Node ESM + 内置 HTTP/SQLite + 普通文件存储，前端普通 HTML/CSS/JS，复用现稿视觉/交互；没有现存业务依赖。仅在必要时引入成熟小型 multipart 或 HTML parser 依赖，先查类型/官方文档；不加 React、Docker、ORM、向量库。
- 单用户 loopback 本地阶段，无账号。`npm start` 监听 **127.0.0.1:4173**，端口占用时明确报告，不擅自暴露网络。环境支持 `PAGENEST_DATA_DIR`（默认 `.data`）、`PAGENEST_PORT`，测试用独立临时数据目录，不能删除用户库。
- 真实文件输入，原始字节落普通文件，SQLite 保存 folder/material/file/reading metadata。UI 保存成功必须来自服务端提交并读回；同 HTML SHA-256 去重，单个导入请求标识幂等。关联附件未成功不能报已附。所有元数据引用 UUID 文件 ID，禁止用户路径直读；文件写失败清理本次临时文件，不损毁已存文件。
- 最小 API 由 Writer 命名并在 README 记录：health、library/folder CRUD、multipart import、material edit/move/trash/restore、source 补充、file download/preview、reading get/update。返回 JSON DTO，失败有清楚中文信息。folder `{id,name}`；material `{id,title,folderId,htmlFileId,sourceFileId,sourceUrl,deletedAt,createdAt,lastReadAt}`；file `{id,name,mime,size,sha256}`；reading 分 material/view 保存 `{scrollTop,page,updatedAt}`。缺省 folderId=null 是未分类。
- 校验：一次一个 .html/.htm ≤20MB；一个可选 .pdf/.txt/.html/.htm ≤50MB；总请求上限略高于二者和；标题 trim 后 1–120；文件夹 1–30、去空格不重名/不占系统名；链接仅 HTTPS。示例：重复 HTML 返回已有 materialId 供打开，不覆盖；删夹保留资料归未分类；TXT `<script>` 只显示文字；无原文给补充入口。
- 三界面和文件夹/搜索/最近阅读、编辑/移动/删夹保留资料、回收站恢复、文件下载按既有方案实现。导入表单保留失败内容，重复提交禁用；首屏空库，不伪装已导入示例。可选独立示例文件放 examples，用明确按钮导入真实文件流程。

## 五条不变量

1. 原文件保留字节；资料/附件/文件夹/位置重启可读，服务端权威成功后才提示。
2. 展示 HTML 使用 iframe `sandbox="allow-scripts"`（不授予 same-origin、弹窗、顶层导航、表单等）及响应级 CSP：禁联网/嵌套页面/对象/base/form，静态 data 图片、内联 CSS/JS 和简单离线交互可用；应用壳同时限制 `frame-src 'self'`，禁止子页面通过自己的 navigation 绕过外联限制。不得把导入内容插主 DOM。展示副本与原文件分开。API Host/Origin 防跨站写入。
3. 阅读桥只处理指定 iframe Window 的有界 position/size 消息，不接受业务操作；保存整理/原文独立位置，切换与再开恢复。固定宽度内容仅阅读区域横向滚动，提供适合屏幕/原始大小；320/390px 应用壳无横溢出。
4. PDF 优先浏览器原生预览，提供页码跳转及下载/新窗 fallback；原生预览不能自动报告页内滚动时如实注明，不能伪报精确恢复。TXT 安全纯文本；原文 HTML 同等隔离。链接与文件只是用户绑定，不声称验证来源。
5. 无登录和同步能力不得显示为已实现；服务只 loopback，验证小样本/低并发，不扩展安全/性能专项。
