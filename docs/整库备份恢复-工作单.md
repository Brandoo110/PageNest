## 合同与不变量（五条）

1. 版本1格式使用Node内置gzip压缩UTF-8 JSON，外部扩展.pagenest，包含固定format/version、导出时间、folders/materials/files/reading；files附base64原始字节和已有name/mime/size/sha256。导出包含回收资料、空分类、所有原件（包括保守保留旧来源文件）、来源链接/createdAt/lastReadAt/双视图位置。requests是传输幂等账本、display和正文索引为派生数据，不打包；恢复从原件重建派生物。不导出代码、环境、Key、绝对本机路径或数据库文件。GET `/api/backup/export` 返回attachment/no-store，导出时元数据/原件一致快照、完整校验再成功；界面不得失败仍下载假备份。
2. POST `/api/backup/restore`接受单个binary备份（独立有界reader，别复用16KB json表单），沿用Host/Origin。压缩上传最多100MiB，解压JSON最多150MiB，原字节总量最多100MiB，记录数最多2000；使用内置有界gunzip，不能先无界解压再检查。校验版本/schema/唯一ID/已知MIME/单文件既有限额/真实长度/严格base64/sha256、分类名/标题/HTTPS链接/有限阅读位置/时间和引用完整性，禁止任意路径或SQL执行。坏包、截断、未知版本、hash不符、缺文件/重复ID/非法引用均在写入前失败且当前库不变。限制可在README和超限错误里简短说明。
3. 恢复语义为合并，无清空或覆盖操作：分类同名复用，否则创建；资料按原HTML sha256精确去重（含已有回收资料），已存在整条跳过不改分类/来源/位置/回收状态。新增条目重新分配本机UUID并映射所有引用，保留标题/日期/来源/回收和阅读值。空库恢复保留全部原件/空分类/关系和状态；已存在库重复恢复不会重复条目。源文件名字仅metadata，不用来构造路径；文件落盘只用本机生成UUID。孤立旧来源原件按sha256+mime+name复用，保留不同原文件名，避免重复恢复无限增加；全包先验证再以既有transaction模式写入，DB/文件失败回滚且清理本次新文件，不破坏旧文件。
4. 必须用既有inspectHTML/textDisplay/原件验证重建display与搜索正文，不信任备份里的展示HTML或索引。隔离CSP/sandbox保持；备份title/filename/snippet/error展示全部转义。恢复失败/上传中按钮状态准确、可重试；恢复成功refresh真实API，不模拟计数。scope限定当前本机库，不自动读取其它目录或外发。
5. 不恢复正式库来做测试。唯一Writer只在临时虚构库完成端到端导出→空库恢复→重启/正文搜索/下载原字节/位置→再恢复去重；正式已点名4份HTML保持。完整候选由原代码管理执行一次有界只读事务/反例审核，复用Writer证据，只补实际缺口，再由总控ACCEPT/正常功能PR；未ACCEPT不运行正式.data。
