## 五条不变量

1. 原 HTML/来源文件字节不变；派生展示、目录与全文独立。无登录服务仅 loopback，Host/Origin 与上传上限保留；内置 AI/Key/DeepSeek/同步/部署均不恢复。
2. HTML 永远 opaque `sandbox="allow-scripts"`，不加 same-origin，不注入 shell DOM，CSP 禁网络。postMessage 限定当前 iframe/parent、channel/type 和有界数据；iframe 无业务写指令。
3. 导入和保存只有服务器成功才显示成功；重复跳过且不覆盖既有分类/状态/备注，失败保持输入可重试。小批串行复用现有每文件原子 import/idempotency，禁止大后台队列。
4. 新状态/备注持久化并进入整库备份；旧库/旧 version1 备份可读取，新增 version2 明确校验、非法输入和失败恢复不留下半库。不清理/重置正式数据，不伪造整库字段不变。
5. 保留 48/55px 紧凑顶栏、同栏 HTML/原文、已有搜索高亮及阅读位置。desktop/mobile 可用，小样本 focused 验证；不引入重型工程、富文本编辑器、账号或统计面板。

## 三个完整功能里程碑（按功能分支逐步合并）

### A · 批量导入 / `codex/batch-html-import`

Allowlist：`public/app.js`、`public/style.css`、必要 `public/index.html`、`tests/local.test.js`（仅确需测试既有接口时）、`README.md`，本工作单由 Git 管理复制；证据只写 `artifacts/batch-import/**`，不进 Git。Backend 无改动。

支持资料库入口与导入页一次选择/拖放多份 HTML；一份仍保留原有单份标题/可选来源/保存阅读流程。批量统一分类，逐份自动标题、结果与打开成功条目；先检查再串行 `/api/import`，保持每份 requestId 重试身份，重复409显示跳过。最多20份、每份20MiB、总100MiB，按文件逐一处理而非同时缓存全部原字节。非HTML/空文件/过大逐项明确错误；已成功不重导，失败可重试。外部资源按该文件明确确认并能重新取得受限预览（预览服务仅存3份，不能依赖失效 URL）；不静默 acceptExternal。取消停止尚未开始项，在途结果读回，已保存保留；不把取消显示成回滚。拖放不触发浏览器文件导航。批量原文随后在单资料补充，不猜来源配对。

验收：2份有效+1重复+1无效，统一分类，真实新增2/跳过1/失败1；有限外部资源确认/未确认、重试或取消保留已成功结果，single import 不回归；1440与320/390只各一张关键截图。语法 `npm run check`，必要既有 focused 或浏览器小样本，不重跑无关后端全量。

### B · 章节目录 / `codex/reader-outline`

从 A 合入后的 accepted main 开始。Allowlist：`src/html.js`、`src/bridge.js`、`src/store.js`（仅目录读取/派生 display）、`src/server.js`（只读目录 route）、`public/app.js`、`public/style.css`、必要 `tests/local.test.js`、`README.md`；证据 `artifacts/reader-outline/**`。

HTML 静态 h1–h6 导航，排除隐藏/head/template 等已知不可见标题，非空，按顺序与层级最多200项。复用 htmlparser2；展示副本对可导航标题增加唯一保留属性 `data-pagenest-heading="pn-heading-N"`，先移除输入里的同名属性，保留原 id，避免改变原锚点。outline `{id,label,level}` 与 display 由同一解析规则生成，label 有界（200字符），旧 HTML 的派生展示按版本或读取时更新，无原件迁移。新增 material只读 outline 接口不得开放任意路径/DOM。HTML侧按钮“目录”，desktop窄侧栏可收起、mobile抽屉点击后自动收起，无目录给简短空态，原文不提供此 HTML目录。跳转只从 parent 发 channel `pagenest-reading` / type `heading` + 正则 `^pn-heading-[0-9]{1,3}$` 白名单 ID；bridge 检查 event.source===parent 并只对受控标记元素 scrollIntoView，继续原位置report，不能调用业务 API。parent 继续只接受当前iframe位置/尺寸消息。不得 iframe 同源读取DOM或开放业务消息。
